# Gemini / Neon — 会話アーカイブ

このディレクトリは、クラウドブラウザーで開いたGemini会話と、その保存手順をまとめています。

## まず読むもの

1. [トポス創発法.md](トポス創発法.md) — Gemini会話48往復（ユーザー48件・Gemini回答48件、計96発言）を画面順にMarkdownで収録。
2. [作業記録](sagyo_workflow/README.md) — 記録の作り方、確認方法、再利用の考え方。
3. [進捗ログ](sagyo_workflow/progress.md) — 作業とコミットを時系列で記録。
4. [判断記録](sagyo_workflow/decisions.md) — 保存場所や書式を選んだ理由。
5. [再開用の状態](sagyo_workflow/state.md) — 作業が中断したときの再開点。
6. [会話記録テンプレート](sagyo_workflow/conversation-template.md) — 次の会話を同じ要領で整理するための雛形。

## 会話表示

GitHub の標準 Markdown で読みやすいチャット表示になるよう、話者見出し（👤 ユーザー／✨ Gemini）、回答内の見出し、箇条書き、コードフェンス、区切り線を使います。元画面の色、余白、操作ボタンなどMarkdownで再現できない表示や、確認できない時刻は作り足しません。アカウントに結び付くスレッドURLやIDは公開記録に含めません。会話本文とブラウザー操作ログは別ファイルに分けます。

## 更新時のルール

- 新しい記録は既存文書を確認してから追加します。
- 話者の文章は原文を基本にし、数式や記号の空白を画面抽出の都合で整えた場合は作業記録に明記します。作業者の要約や解釈は会話本文と分けます。
- ひとまとまりの成果を整えた時点でコミットし、成功したコミットSHAと残作業を進捗・状態に記録します。
- 対象を取り違えた場合は正しい会話本文へ差し替え、誤りと訂正を作業記録に残します。
- `sagyo_workflow/state.md` を再開時の入口として維持します。
