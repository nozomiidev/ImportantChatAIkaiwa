# Gemini / Neon — 会話アーカイブ

このディレクトリは、Gemini をクラウドブラウザーで開いた会話と、その記録作業の手順をまとめたものです。

## まず読むもの

1. [会話記録](conversation.md) — 話者ごとの見出しと引用で、チャットの読み順を再構成しています。
2. [作業記録](sagyo_workflow/README.md) — 記録の作り方、確認方法、再利用の考え方。
3. [進捗ログ](sagyo_workflow/progress.md) — 作業を時系列で記録。
4. [判断記録](sagyo_workflow/decisions.md) — 保存場所や書式を選んだ理由。
5. [再開用の状態](sagyo_workflow/state.md) — 作業が中断したときの再開点。
6. [会話記録テンプレート](sagyo_workflow/conversation-template.md) — 次の会話を同じ要領で整理するための雛形。

## 会話表示

GitHub の標準 Markdown だけで読みやすいチャット風の表示になるよう、話者見出し、引用ブロック、連番、区切り線を使います。元の UI の色や正確な時刻など、記録から確認できない表示は作り足しません。会話本文とブラウザー操作ログは別ファイルに分けています。

## 更新時のルール

- 新しい記録は既存文書を確認してから追加します。
- 話者の文章は原文の表記を維持し、作業者の要約や解釈は会話本文と分けます。
- ひとまとまりのファイルを整えた時点でコミットし、進捗・状態・コミット SHA を更新します。
- `sagyo_workflow/state.md` を再開時の入口として維持します。
